## Government Methods

A student-run initiative in the Department of Government at **Georgetown University**.

Maintained by graduate students and supported by the Department, Government Methods gathers the
tools, workflows, code, and conceptual frameworks we return to in our research and teaching. 

### What's here

| | |
|---|---|
| **[Methods Brown Bag](https://govtmethods.github.io/methodsbrownbag/)** | A recurring workshop series. Graduate students present tools, workflows, and research design.  |
| **[Math Camp](https://govtmethods.github.io/mathcamp/)** | Refreshers in mathematics, statistics, and computation for the start of the year. |
| **[govtmethods.github.io](https://govtmethods.github.io/)** | The site itself — both series, plus notes and contact. |

Each series is also available as a single PDF, linked from its own page.

### Presenting a session

Sessions are written by the people who present them. If you presented one and would like it on the
site, **[Submitting a Session](https://govtmethods.github.io/submit.html)** explains what to send —
no GitHub account, and nothing to install.

Editors maintain the site itself. If you would like to join as one,
[get in touch](https://govtmethods.github.io/ask.html).

### How it's built

Everything is written in [Quarto](https://quarto.org). Each repository renders itself with GitHub
Actions and publishes to GitHub Pages; R environments are pinned per project with
[renv](https://rstudio.github.io/renv/), so every build uses the same package versions.
